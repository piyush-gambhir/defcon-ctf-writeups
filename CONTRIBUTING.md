# Contributing

This repository is organized around one independently produced write-up per
challenge.

## A good solution commit contains

- the challenge status changed to `solved`;
- reproducible solver or exploit code under the challenge workspace;
- an original write-up under `writeups/`;
- attribution and an upstream challenge link;
- no unrelated binaries, secrets, tokens, or personal scratch files.

Explain why the solution works. Include failed approaches when they teach
something useful. Avoid copying another team's write-up; link to useful prior
art instead.

## Active competitions

This catalog contains ended events. If future events are added, do not publish
flags or solutions while the event is active, and follow the organizer's rules
on collaboration and AI assistance.
